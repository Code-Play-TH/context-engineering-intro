# KOL Management System - Frontend

Next.js frontend for the KOL Management System.

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open browser
http://localhost:3000
```

## Features

-   ✅ Login page with JWT authentication
-   ✅ Dashboard with statistics
-   ✅ KOL management (list, create, view)
-   ✅ Campaign management
-   ✅ Responsive design
-   ✅ Auto token refresh

## Tech Stack

-   Next.js 14 (App Router)
-   TypeScript
-   Tailwind CSS
-   TanStack Query
-   Zustand
-   React Hook Form
